# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| 0.1.x | No |

Security fixes go to the 0.2 line. 0.1.0 does not receive them.

## Reporting a vulnerability

Do not open a public GitHub issue for a security report.

Use GitHub private vulnerability reporting:

<https://github.com/balamuruganpg/promptregress/security/advisories/new>

Include the version you ran, what the issue is, and a way to reproduce it. Leave out API keys, tokens, and other secrets. `promptregress doctor` prints environment-variable names only. A report should do the same.

The maintainer will acknowledge the report and ship a fix before any public write-up.
